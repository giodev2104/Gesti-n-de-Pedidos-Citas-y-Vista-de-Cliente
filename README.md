📦 Sistema de Gestión de Pedidos/Citas y Vista de Cliente

Aplicación Web Dual: Portal interactivo de solicitudes para el cliente y Dashboard de control interno para la empresa.

⚡ Demo en Vivo (Sin Instalación)

Accede directamente desde cualquier navegador sin necesidad de instalar nada:

👉 Ver Demo: https://giodev2104.github.io/Gesti-n-de-Pedidos-Citas-y-Vista-de-Cliente/

💼 Impacto y Valor para el Negocio

Conecta las solicitudes del cliente directamente con la gestión operativa del negocio. Mantiene al cliente informado del estado de su servicio en tiempo real y ofrece a la directiva métricas clave e indicadores diarios de rendimiento.

Alternador de Vistas (Dual View): Cambia con un solo clic entre la perspectiva del cliente y el panel del administrador.

Control de estados: Cambio dinámico de estados de pedido (Pendiente, En Proceso, Completado).

Métricas en vivo: Dashboard con resúmenes visuales de ingresos y volumen de peticiones.

🛠️ Personalización a Medida

El sistema se puede adaptar a las necesidades específicas del cliente:

Personalización de campos de reserva, servicios o productos ofertados.

Integración con sistemas de cobro online (Stripe, PayPal) o calendarios (Google Calendar).

Configuración de notificaciones automáticas por email o SMS.
